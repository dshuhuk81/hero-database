# Hou Yi Hero Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The owner requires native execution without subagents, bot runs or automated tests.

**Goal:** Add Hou Yi as a complete Legendary Archer with his approved mechanics, talents, effects, UI art and animation-ready board figure.

**Architecture:** Keep combat rules in a focused `houyi.js` module and let `sim.js` own state changes and emitted presentation facts. Extend the existing generated roster, talent, skin, procedural FX and authored-FX paths instead of introducing a new hero framework. Produce and approve the UI master and animation master separately before deriving runtime assets.

**Tech Stack:** Astro 7 static site, plain JavaScript/TypeScript, JSON data, PixiJS renderer, built-in ImageGen, existing Node/Python asset scripts, PixelLab clip pipeline.

**Spec:** `docs/superpowers/specs/2026-10-10-hou-yi-hero-design.md`

## Global Constraints

- Preserve the approved Hou Yi mechanics and first-pass values exactly.
- Internal ID is `houyi`; rarity is `legendary`; class is `Archer`; slot is `platform`.
- Mythology memberships are exactly `divine-guardians` and `wildborn`.
- UI art and animation-source art are separate approvals but depict the same identity and equipment.
- Generate no audio, add no production dependencies, upload nothing to R2 and run no production build.
- Owner override after spec approval: run no automated tests, simulation tests, bot tests, sweeps or balance runs during this implementation.
- Do not spawn subagents or automated reviewers; preserve usage for implementation and asset generation.
- Do not overwrite published assets. New files use Hou Yi's new unversioned runtime names or versioned artifact-master names.
- Stop after every task for explicit owner approval before starting the next task.
- `git diff --check`, targeted source inspection and visual inspection are permitted; they are not gameplay validation and do not execute the test suite.

## Review Focus

- Target allocation must remain deterministic when enemies tie on Flyer status and path progress.
- A failed cast must preserve ultimate charge and sun counters; a valid cast consumes counters once.
- Evolution V, Sun Hunter and Droughtbreaker must compose without unlimited arrows or recursive explosions.
- UI art and animation art must keep the same face, costume, weapon and proportions while using different poses.
- Missing authored FX must leave target markers, projectile travel and gameplay readability intact.
