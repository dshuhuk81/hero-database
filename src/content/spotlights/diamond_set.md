### Core Mechanic

Set provides lifesteal and ATK% buffs to the team and can function as an armor shred support for the Diamond team. His value is frequently misunderstood — like Poseidon, what Set *actually* does in a fight requires understanding the armor calculation mechanics.

The EG player notes that "knowing how to use Poseidon and Set literally defines a good pusher vs. a mediocre one" — Set is the Spade cross-over that Diamond teams borrow. His lifesteal keeps the frontline sustained through Poseidon's grouped cluster fights.
